# Example: “হাদি কে?” (v3, 2:56, Vox-paper, Bangla)

The first video made with this kit, kept as a worked reference.

- `script.json`: the 17 VO lines exactly as voiced (ElevenLabs eleven_v4, voice “Rayhan”).
- `vo_dur.json`: clip lengths after trim + tempo 1.06 (scene duration = VO + 0.55 s).
- `index_v3_reference.html`: the full v3 scene file from **before** the engine was split out. Its CSS/JS were
  inlined and fonts loaded from `node_modules/`. Use it to borrow layouts, not to run as-is.
  Images aren't included (third-party photos), so they won't load.

What went wrong in v1–v3 and the fixes now built into the tools: `../../docs/lessons-learned.md`.
